# Portafolio de Analisis y Ciencia de Datos

Este repositorio esta dedicado a almacenar mis proyectos, avances, practicas y desarrollos en el area de analisis de datos, ingenieria de datos y visualizacion.


## Tecnologias y Herramientas

Actualmente utilizo las siguientes librerias y herramientas principales:

* Procesamiento y Analisis: Python, Pandas, NumPy
* Ingenieria y Limpieza: Pandas, NumPy
* Visualizacion: Matplotlib
* Interfaces y Dashboards: Streamlit
